## Factual errors

1. **Check mode is V=0 only (line 82).** "If either V or M are 0 … it runs check mode" is wrong. M=0 with a version of 1–11 draws a code, deciding auto mode by itself. The paragraph also says the check "passes control back to the BASIC program to set V and M", but the engine never sets anything. Suggested replacement:
   > With V=0 the engine only checks the text and draws nothing. It returns the length and the mode it would use, so your program can pick a version and set M before calling again with V=1-11 to draw. A draw call with M=0 decides the mode by itself.

2. **`fPart(Ans/2)` gives 0 or 0.5, not 0 or 1 (line 86).** Use `2fPart(Ans/2)` for the mode bit. The range "0≤Ans≤65531" also overlaps "Ans=0: drawn", since an empty ASCII text checks as 0 too. Saying it applies to check calls (V=0) only fixes that.

3. **65534 isn't "an unknown error" (line 89).** The engine never returns it. It's what's left in Ans when the engine didn't run at all, and only if the caller stored 65534 in Ans right before `Asm(`, as prgmQR does. Suggested:
   > Ans=65534: the engine didn't run (for example, prgmθQR is missing or archived). Store 65534 in Ans right before Asm( to detect this.

   You might also add that line (`65534` alone on a line) to the example before `Asm(prgmθQR`.

4. **E=3 can also answer 65535 (line 67).** It does so when there isn't enough free RAM to make Str3.
