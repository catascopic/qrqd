.CODECHAT
.CodeChat prototype: encrypted messages (AES-SIV) written as
.digits. Keys come from the keyring appvar CCKEYS (made by
.tools/codechat.py on the PC); the message counter is in appvar
.CCSTATE; sent digits go to the NoteFolio note CCOUT, which
.prgmQR can draw. Design: docs/design.md, "CodeChat".
.
.Message: header (6 bytes: 10h + flags, key ID, 4-byte counter)
.+ tag (16) + ciphertext. Flags: bit 0 compact text, bit 1 odd
.character count (compact only).
.
.Memory, L₁: header 0-5, tag 6-21, text 22-321, key entry 330
.(name 330-337, my side 338, K1 339-354, K2 355-370), round keys
.380-555, CMAC subkeys 576 and 592, S2V's D 608, CMAC output
.624, scratch block 640, CTR counter 656, temp 672, a name for
.display at 690. L₃: the typed characters (ASCII).
.
