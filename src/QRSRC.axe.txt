.θQR
.QR code engine for prgmQR : versions 1-11,
.EC level L, mask 0.
.Called from BASIC with Asm(prgmθQR); inputs are OS variables
.(a missing one reads as 0), the answer comes back in Ans.
.Comments are stripped by tools/build.py, so they cost nothing
.on the calculator. Details: docs/design.md, docs/API.md.
.
.Inputs:
.  E  source: 1 text in Str1 (tokens), 2 bytes in ʟBIN,
.     3 text of the NoteFolio note named in Str2,
.     4 list the NoteFolio notes into Str3 (Ans = how many)
.  V  version 1-11, or 0 to only check the text
.  M  mode: 0 auto, 1 ASCII (byte mode), 2 alphanumeric.
.     After an auto check, prgmQR sets M from the Ans bit.
.  N  number of characters to encode
.  O  number of characters to skip first (split messages)
.Ans:
.  check: 2·length+1 if alphanumeric, 2·length if byte mode
.  draw: 0 (the code is in the graph buffer, shown)
.  65533 bad character (its position in B)
.  65532 too long (over 32765 characters)
.  65535 bad input (bad E/V/M, or the input doesn't exist)
.  list (E=4): the number of notes
.B: position of the first problem character (a note in byte
.  mode only warns: Ans is a normal result with B≠0)
.
.Static data. inData( searches up to a 0 byte, so the
.tables searched that way end in 00.

.0 when the appvar is archived; then it is opened as the file
.Y₁ (Q stays 0, and RB reads through Y₁). U = appvar size, at
.least 27 for an empty note (header 24, the 00 end, 2 bytes).
Lbl NH
0→X
GetCalc(L₁+700)→Q
If Q
{Q-2}ʳ→U
Else
Return!If GetCalc(L₁+700,Y₁)
{Y₁-2}ʳ→U
End
ReturnIf U<27
.The first 4 bytes must be the NoteFolio signature
For(J,0,3)
sub(RB,J)
ReturnIf C≠{J+GDB8}
End
1→X
Return

.NF: open the note named in Str2. X=1 if found, T = text
.length. The name is copied to L₁+701 as tokens, which for A-Z,
.0-9 and θ are the same bytes as in a VAT name. A space (29h)
.ends it, so a name padded with spaces (from Str3) works too.
Lbl NF
0→X
GetCalc("Str2")→Z
Return!If Z
{Z-2}ʳ→U
0→L
While L<U
If {Z+L}=41
L→U
Else
{Z+L}→{L+L₁+701}
L+1→L
End
End
.1-8 characters (L=0 wraps around, so it fails too)
ReturnIf L-1>7
.Make the OP1 name: type 15h (appvar), the name, 0
21→{L₁+700}
0→{L+L₁+701}
sub(NH)
Return!If X
.The text runs from byte 24 to a 00h; the appvar size bounds
.the scan (U-24 bytes at most)
0→T
U-24→U
While T<U
sub(RB,T+24)
If C
T+1→T
Else
T→U
End
End
Return
