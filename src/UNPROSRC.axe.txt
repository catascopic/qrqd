.UNPROT
.Tool: unprotects the program named in Str1 (VAT type 06h,
.protected program → 05h, program) so TI Connect will copy it
.off the calculator. Usage: "θQR"→Str1:Asm(prgmUNPROT
.A prgm token in front of the name is allowed. The program must
.be in RAM. Recompiling it with Axe protects it again.

.S = the name's tokens, N = their count (the size word)

End

End

.P-7 downward; the next entry starts at P-7-length.

.for A-Z, 0-9 and θ)

End
End
